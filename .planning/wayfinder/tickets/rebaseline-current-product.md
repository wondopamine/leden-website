## Question

What customer, ordering, staff, reliability, security, content, and visual
capabilities actually work in the current repository and rendered application,
which are incomplete or misleading, and which parts of the existing roadmap are
now stale?

## Resolution comment

Resolved in [Current product re-baseline](../research/current-product-rebaseline.md).
The repository is a polished functional prototype whose brand system and core
journeys should be preserved, but it is not production-ready: order integrity,
admin authorization, outage truthfulness, service recovery, content ownership,
and several mobile/contrast defects must be decided before further execution. The
existing roadmap is stale relative to shipped code and should not drive the next
implementation plan.
